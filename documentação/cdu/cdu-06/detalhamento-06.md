# CDU06. Logout

- **Ator principal**: Clientes e Administração.
- **Atores secundários**: Nenhum.
- **Resumo**: Cliente ou Administração clica em Logout na página de Usuário
- **Pré-condição**: Cliente ou Administração está na página de Usuário
- **Pós-Condição**: Cliente ou Administração está deslogado e na página principal

## Fluxo Principal
| Ações do ator | Ações do sistema |
| :-----------------: | :-----------------: | 
| 1 - Cliente ou Administração clica em "Logout" na página do Usuário |  | 
|  | 2 - O Sistema desloga da conta e retorna a página principal | 


> Obs. as seções a seguir apenas serão utilizadas na segunda unidade do PDSWeb (segundo orientações do gerente do projeto).
